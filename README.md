# 🤖 Academic Research Bot

بوت تلجرام ذكي لتوليد الأبحاث الأكاديمية بلغات متعددة.

## 🌍 اللغات المدعومة
- العربية
- الإنجليزية  
- الروسية

## ✨ المميزات
- توليد محتوى بالذكاء الاصطناعي
- تصدير إلى مستندات Word
- واجهة تفاعلية سهلة
- دعم متعدد اللغات

## 🚀 النشر على Render
1. انسخ هذا المستودع
2. سجل في Render.com
3. أنشئ خدمة ويب جديدة
4. صلح مع GitHub
5. اضبط متغيرات البيئة
